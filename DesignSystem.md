## Design System

One visual language.

One spacing system.

One typography scale.

One interaction style.

Every page, component, and visualization should feel like part of the same platform.

---

# 1. Colour System

The palette is derived from environmental and geographical systems rather than software products.

The visual identity should evoke:

- Ocean depth
- Coastlines
- Satellite imagery
- Terrain mapping
- Storm systems

Never use colors simply because they appear modern or trendy.

---

# 9. Cards

Cards should prioritize readability.

Every card must answer one question.

Bad card:

Multiple unrelated metrics.

Good card:

One metric.

One insight.

One recommendation.

---

# 10. Dashboard Metrics

Metric cards should display:

Value

↓

Trend

↓

Interpretation

Example:

125

Potentially Exposed Buildings

Moderate Historical Exposure

---

# 11. Charts

Preferred:

- Area Charts
- Line Charts
- Horizontal Bar Charts

Avoid:

- Pie Charts
- Donut Charts
- Radial Charts

Geospatial information is already complex.

Charts should reduce complexity.

---

# 18. Visual Rule

Whenever a visual decision is uncertain, prefer the option that makes the platform feel more like:

A professional geospatial intelligence platform.

Not:

A startup landing page.

Not:

A generic analytics dashboard.

Not:

An AI application.
